## 1. Опис структури та використання колекцій
- **HashSet<string> (Унікальні ID)**: забезпечує швидку перевірку дублікатів транзакцій за O(1).
- **Queue<Transaction> (Черга FIFO)**: зберігає транзакції строго в порядку надходження на обробку.
- **Stack<Transaction> (Історія LIFO)**: дозволяє швидко скасувати останню оброблену транзакцію (Undo).

## 2. Відповіді на контрольні запитання

1. **У чому різниця між List<T> та HashSet<T>?**  
   List<T> — впорядкований список із підтримкою дублікатів (пошук O(n)). HashSet<T> містить лише унікальні елементи без строгого порядку з пошуком за O(1).

2. **Коли доцільно використовувати Queue<T> замість List<T>?**  
   Коли потрібна дисципліна FIFO (First-In, First-Out) — обробка елементів у порядку їх черговості.

3. **Приклад реальної задачі для Stack<T>.**  
   Функція скасування дій (Undo/Redo) у текстових та графічних редакторах, стек викликів функцій.

4. **Складність операції Contains() для HashSet<T>?**  
   У середньому O(1), оскільки пошук виконується за хеш-кодом елемента.

5. **Чому Queue<T> — FIFO, а Stack<T> — LIFO?**  
   - **FIFO** (First In, First Out): перший прийшов — перший пішов.  
   - **LIFO** (Last In, First Out): останній прийшов — перший пішов.

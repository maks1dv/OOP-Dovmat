##  Відповіді на контрольні запитання

1. **У чому полягає різниця між override та new при роботі з методами?**
   - `override` перевизначає віртуальний метод базового класу і реалізує динамічний поліморфізм (виклики залежать від типу об'єкта в пам'яті).
   - `new` створює абсолютно новий метод у похідному класі, який приховує метод базового класу (виклики залежать від типу посилання-змінної).

2. **Що таке поліморфізм і як override його забезпечує?**
   - Поліморфізм — це здатність об'єктів різних типів оброблятися через єдиний інтерфейс базового класу.
   - `override` забезпечує його за допомогою таблиці віртуальних методів (VMT) та пізнього (динамічного) зв'язування.

3. **Чому при використанні new не відбувається динамічного зв’язування?**
   - Тому що метод із модифікатором `new` не записується у таблицю віртуальних методів базового класу, а є окремим методом похідного класу. Для нього застосовується раннє (статичне) зв'язування під час компіляції.

4. **Коли доцільно використовувати new замість override?**
   - Коли базовий метод не оголошено як `virtual`, або коли потрібно свідомо розірвати поліморфний зв'язок і зберегти базову поведінку при виклику через базове посилання.

5. **Що станеться, якщо забути вказати new при приховуванні методу?**
   - Програма скомпілюється і метод все одно буде приховано, проте компілятор видасть попередження (warning) про приховування успадкованого члена.
